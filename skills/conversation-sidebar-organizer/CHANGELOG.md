# Changelog: conversation-sidebar-organizer

## 0.3.0 - 2026-10-27

- 首轮信息模糊时允许保守命名并记录 `provisional` 状态；原任务补充明确后最多自动完善一次。
- 明确状态来源、摘要保留、旧记录兼容、手动覆盖、失败与无工具处理边界。
- 同步插件版本与自动命名 README 示例，并增加手工验收场景。

## 0.2.1 - 2026-09-21

- 增加可移植插件清单与仓库 marketplace 分发入口，支持公开插件目录和跨 Agent 安装。

## 0.2.0 - 2026-09-12

- 对外名称调整为 `Chat Naming / 对话命名助手`。
- 明确支持 Cursor、Codex、Grok、Claude 等工具复用命名规则。
- 区分跨工具命名能力与 Codex 宿主专属的侧边栏操作。
- 建立独立 Skill 版本和发布标签。

## 0.1.0 - 2026-09-04

- 首次提供对话命名与 Codex 侧边栏整理能力。
