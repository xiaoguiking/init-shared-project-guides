# 对话命名助手 v0.3.0 手工验收

以下场景用于人工核对 Skill 规则；宿主改名工具执行与否以真实运行结果为准。

| 场景 | 输入/前置状态 | 预期 |
| --- | --- | --- |
| 明确首轮 | 新对话明确提出对象与目标 | 按 `领域｜对象｜目标` 命名；工具成功后记录来源、标题、`completed`、完善次数 0。 |
| 模糊后明确 | 首轮可概括但对象或目标不明；工具成功写入保守标题；随后补充原任务对象和目标 | 首次记录为 `provisional`、完善次数 0；随后只允许完善一次，成功记为 `completed`、次数 1。 |
| 相同标题无需写入 | 原任务补充明确后生成的候选标题与现有标题相同 | 不调用工具；直接记为 `completed`、完善次数保持 0。 |
| 明确首轮后追问 | 首轮对象和目标明确，命名成功后继续补充 | 不自动改名。 |
| 主题转向 | 有 `provisional` 状态后，用户转向新主题或新任务 | 不触发完善，也不跟踪新主题。 |
| 完善后不再改 | 上一场景已成功完善；再补充信息或转题 | 不自动改名。 |
| 纯问候 | 首轮仅“你好”或空内容 | 不命名，等待可概括内容。 |
| 简单测试 | 首轮“测试一个对话的内容，简单测试下” | 命名为 `工具｜对话功能｜简单测试`。 |
| 固定/停用 | 用户要求固定标题或停用自动命名 | 尊重并记录该选择；停止自动命名/完善，不因后续信息自动恢复。显式命名按用户明确要求执行。 |
| 旧记录 | 有成功命名记录但没有 `provisional` 标记 | 按 `completed` 处理，不自动完善。 |
| 工具失败 | 改名调用失败 | 不记录成功；不消耗完善次数；不反复重试。 |
| 无工具 | 宿主没有改名工具 | 只给建议标题，不声称写入成功。 |
| 压缩丢失 | 摘要中没有状态或来源不明 | 不猜测、不自动完善。 |
| 手动覆盖 | 宿主可读当前标题且与记录的自动标题不同 | 尊重手动标题，停止完善。 |

## 2026-10-27 隔离推演结果

使用 `gpt-6-luna`、`medium` 推理强度，在独立子 agent 中读取 Skill 后推演多轮输入。未调用真实改名工具；以下结果验证模型对规则的理解，不代表宿主自动触发或标题实际写入已经验收。

| 场景 | 观察结果 |
| --- | --- |
| 模糊开发问题 → 问卷 React 表单重复请求 → 数据库索引 | 首轮建议保守标题并记为 `provisional/0`；补充原任务后建议完善标题并记为 `completed/1`；第三轮不改。 |
| React 面试题 → 补充闭包和 Hooks | 首轮 `completed/0`；后续补充不改。 |
| 已有自动标题 → 固定为“问卷排障” → 补充对象 | 按用户原文固定标题，后续不完善。 |
| 只有旧版成功命名记录 → 补充 React 表单 | 按 `completed` 处理，不完善。 |
| 原任务明确，但完善工具模拟返回失败 | 保留 `provisional/0`，不记录成功、不反复重试。 |
| 摘要缺少完整命名状态且当前标题不可读 | 不猜测、不触发完善。 |

上述六组推演符合预期。真实宿主验收仍需先安装 v0.3.0 并迁移旧版常驻规则，再在新对话中检查工具调用和实际标题。用户选择在仓库更新后通过 CC Switch 手动更新，当前本机配置仍保留旧版；其余表内场景尚未逐一运行。
